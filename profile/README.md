<p align="center">
  We are a team building <b>software for surveying and geodesy</b>.<br />
  We design web and Windows applications and Python libraries that make the work of survey engineers<br />
  faster, more accurate and more collaborative, from the first field measurement to the final report.
</p>

| 🐍 | [**lasca-pypi**](https://github.com/LASCA/lasca-pypi) | A Python library of surveying functions: fundamental problems, traverse adjustment, geometric and trigonometric leveling, tachymetry reductions. | Python 3.11+ · NumPy | 🛠️ In development |

<h3 align="center">Our mission</h3>

<p align="center">
  To bring modern software engineering to rigorous surveying and geodetic computation.<br />
  We want students and engineers to have reliable tools for complex calculations,<br />
  data processing and interactive visualization, without fighting their software.
</p>
