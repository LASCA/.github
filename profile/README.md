## About Us

**LASCA Developers** (Land Surveying Computations Applications) builds practical software for land surveying, geodesy, topographic data processing, and civil engineering.

Our mission is to bridge modern software engineering with rigorous geodetic and topographic computation—giving survey engineers reliable tools for complex calculations, data processing, and interactive visualization.

## Core Projects

| Project | Category & Purpose | Tech Stack | Status |
|---|---|---|---|
| [**LASCA**](https://github.com/LASCA/LASCA) | Production desktop application for topographic survey computations, network adjustments, and interactive geodetic visualization. | React, Vite, Tailwind CSS, Python 3.11+, Flask Local Proxy, PyInstaller | 🟢 Production Ready |
| [**lasca-pipe**](https://github.com/LASCA/lasca-pipe) | Decoupled, pure-Python geodetic processing engine and survey calculation pipeline. Supports fundamental topographic problems, traverse adjustments, geometric and trigonometric leveling, and tachymetry reductions. | Python 3.11+, NumPy, Setuptools | 🛠️ In Active Development |

## Tech Stack & Tooling Architecture

- **Frontend:** React, Vite, Tailwind CSS
- **Core Computation Engine:** Python 3.11+, NumPy, Setuptools
- **Desktop Runtime:** Flask Local Proxy, PyInstaller
- **Security & Cloud:** Clerk authentication, Windows DPAPI
